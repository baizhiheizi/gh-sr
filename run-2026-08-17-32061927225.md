## Verified contracts

- **sh -c wrap placement:** the `innerCmd := "sh -c " + hostshell.PosixSingleQuote(pruneInnerDockerCacheScript(containerName))` line runs **before** the `DockerExecCommand` concatenation, so the rendered docker exec is `docker exec "name" sh -c '<script>'` (not `docker exec "name" "<script>"`).
- **Wrapper prefix preserved:** the `|| { echo "inner docker cache prune in <name>: failed" >&2; exit 1; }` outer wrapper still emits the pre-fold descriptive prefix when the inner exec fails; the inner script's "inner dockerd not responding" stderr still reaches the caller via `h.Run` when the probe fails.
- **Test pinned:** the new test checks for the `sh -c '\n` literal sequence, which only the wrapped variant emits — the host-side shell in the surrounding clear body would never produce that exact sequence, so a future refactor that drops the wrap fails the test loudly.
- **PR #412 supersession:** PR #412's diff applies to the standalone `pruneInnerDockerCache` function which PR #411 removes. Either PR #412 no-ops against PR #411's tree, or it conflicts at that line; either way the fix is preserved in `e16c0df`.
