## Discovered contracts (for future reference)

- **MockExecutor stderr surface**: `internal/testutil.MockExecutor.RunFn` returns whatever err the closure provides; it does NOT simulate `runWithCapture`'s stderr-into-error wrapping. Tests that assert stderr-driven diagnostic strings must inject the descriptive text directly into the returned err.
- **`go test -cover` vs `go tool cover -func` discrepancy**: the former reports statement-level coverage; the latter averages per-function coverage (each function is 0/50/100% for atmoic mode). For per-package breakdown, parse `go test -cover` output to match the "coverage: X% of statements" numbers; do NOT use the `go tool cover -func` average.
